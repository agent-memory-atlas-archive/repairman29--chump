# node-organ-manifest.txt — desired PROCESS-LEVEL state for CJ (closetjunky),
# the first owned MUSCLE node (INFRA-3648 slice).
#
# Sibling of scripts/ops/organ-manifest.txt: that file declares desired
# chump-*.service/.timer SYSTEMD unit state, read by organ-reconcile.sh.
# THIS file declares desired state for CJ's raw background bash organs
# installed by scripts/setup/install-node-housekeeping.sh — loop-wrapped
# invocations of tracked scripts/ scripts that are NOT systemd units at all
# (the "supervisor=nohup" fallback path, or any node where systemd isn't the
# chosen supervisor). Nothing in organ-manifest.txt / organ-reconcile.sh can
# see or revive these if they die, the same "designed but never wired into
# the revivable gate" blind spot scripts/ops/process-organ-registry.txt
# already closes for the almanac-vision-keeper class of raw processes. This
# manifest is that same declaration, scoped to the 9 node-housekeeping
# organs.
#
# Format: one directive per line,
#   "<state>  <name>  launcher=<path>  pgrep=<pattern>  heartbeat=<seconds>  # wraps <tracked-script>"
#
#   state       enabled — this organ must be running. A pgrep+respawn heal
#               loop (mirroring scripts/ops/process-organ-heal.sh's shape)
#               reads this file, runs `pgrep -f <pattern>`, and — if
#               absent — respawns via `bash <launcher>`.
#   name        short identifier — matches install-node-housekeeping.sh's
#               ORGANS table and its chump-<name> supervised-unit naming.
#   launcher    the self-contained loop-wrapper script written by
#               install-node-housekeeping.sh's write_runner() at
#               ~/.chump/organs/<name>.sh. This wrapper sources
#               providers.env/cj.env, sets PATH/CHUMP_REPO_ROOT, and either
#               execs the wrapped script once (heartbeat=0, self-looping
#               script) or loops `bash <wrapped-script>; sleep <heartbeat>`
#               forever.
#   pgrep       the `pgrep -f` match pattern. The LAUNCHER path is used
#               (not the wrapped script's own path) because the launcher is
#               what is actually exec'd/looped and stays resident even
#               between wrapped-script invocations; matching the wrapped
#               script's path alone would read a false DOWN during the
#               `sleep <heartbeat>` gap between runs.
#   heartbeat   seconds between wrapped-script invocations; 0 means the
#               wrapped script self-loops forever (no external cadence).
#
# Values below are sourced directly from install-node-housekeeping.sh's
# ORGANS table (the single place cadences are actually configured) — keep
# the two in sync if that table changes.
